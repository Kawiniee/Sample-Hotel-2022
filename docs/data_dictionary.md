# พจนานุกรมข้อมูล

หนึ่งแถวแทนหนึ่งรายการรีวิว คำอธิบายและจำนวนในเอกสารนี้ตรวจจากไฟล์ต้นทาง `samplehotel - Sheet1.csv` ดูรายละเอียดการตรวจสอบใน [Data Understanding](../notebooks/01_data_understanding.ipynb)

## ฟิลด์ต้นทาง

| ฟิลด์ | ชนิดก่อนทำความสะอาด | ความหมายและการจัดการ |
|---|---|---|
| `displayName` | ข้อความ | ชื่อที่แสดงของผู้รีวิว 3 ช่องว่างใช้ `Unknown Reviewer` ไม่ใช้จัดกลุ่มลูกค้า |
| `rating` | จำนวนเต็ม | คะแนนที่ผู้รีวิวให้ ตรวจให้เป็นจำนวนเต็ม 1–5 |
| `publish_platform` | ข้อความ | ช่องทางเผยแพร่ มี `Mobile` และ `Other` ซึ่งไม่มีรายละเอียดช่องทางย่อย |
| `title` | ข้อความ | ชื่อเรื่องรีวิว เก็บตามต้นทาง |
| `text` | ข้อความ | เนื้อหารีวิวเท่าที่มีในไฟล์ เก็บตามต้นทางและตรวจร่องรอยการตัด |
| `clean_country` | ข้อความ | ป้ายประเทศของผู้รีวิวจากต้นทาง 451 ค่า `Not Specified` ใช้ `Unknown` |
| `clean_written_date` | ข้อความ | วันที่เขียนรีวิว แปลงเป็น datetime ใน notebook และส่งออกเป็น ISO `YYYY-MM-DD` |
| `experience_month` | จำนวนเต็ม | เดือนตามฟิลด์ต้นทาง อยู่ในช่วง 1–12 และตรงกับเดือนที่เขียนทุกแถว ความหมายว่าเป็นเดือนเข้าพักยังไม่มีหลักฐานยืนยัน |
| `experience_year` | จำนวนเต็ม | ปีตามฟิลด์ต้นทาง ตรงกับปีที่เขียนทุกแถว ความหมายว่าเป็นปีเข้าพักยังไม่มีหลักฐานยืนยัน |
| `travel_type` | ข้อความ | ประเภทนักเดินทางตามที่ระบุ 328 ค่า `Not Specified` ใช้ `Unknown` |
| `name` | ข้อความ | ชื่อโรงแรม คงที่เป็น `Amari Phuket` |
| `hotel_rating` | จำนวนเต็ม | ระดับดาวโรงแรมตามไฟล์ คงที่ที่ 4 ดาว เก็บเพื่อบอกบริบท |
| `hotel_location` | ข้อความ | ทำเลของโรงแรม คงที่เป็น `Patong` |

## ฟิลด์ที่สร้างใน notebook 02

| ฟิลด์ | ชนิด | นิยาม |
|---|---|---|
| `review_year` | จำนวนเต็ม | ปีจากวันที่เขียนรีวิว |
| `review_month` | จำนวนเต็ม | เดือนจากวันที่เขียนรีวิว |
| `review_month_start` | วันที่ | วันที่หนึ่งของเดือนที่เขียนรีวิว ใช้เรียงลำดับตามปีและเดือน |
| `review_char_count` | จำนวนเต็ม | จำนวนอักขระ Unicode ตามที่ Python นับใน `text` ดิบ รวมช่องว่างและเครื่องหมาย |
| `possible_truncation` | บูลีน | จริงเมื่อข้อความดิบยาว 503 ตัวอักษรและลงท้ายด้วยจุดสามจุด มี 361 รีวิวเข้าเงื่อนไข |
| `rating_group` | ข้อความ | `Low (1-3)`, `4 stars`, `5 stars` ตามคะแนนผู้รีวิว |
